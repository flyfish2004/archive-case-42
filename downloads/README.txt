ДЕЛО № 42 — МАТЕРИАЛЫ ИССЛЕДОВАНИЯ

Исходный архив: test1.zip (673022 байта).
Результат: 1000 файлов, 999 побайтово идентичны, отличается file_0042.txt.
Замена 16 → 42: строка 1; столбцы 42 и 43 (с 1); байтовые смещения 41 и 42 (с 0).
В большинстве файлов: 3. и первые 1000 десятичных знаков π, без округления.

ПОВТОРИТЬ (Python 3.8+, только стандартная библиотека)
1. Распакуйте этот пакет в отдельную папку.
2. Выполните:
   python analyze.py test1.zip --output report.json
3. Независимая проверка, группировка полных bytes без хешей:
   python verify.py test1.zip --output independent-report.json

analyze.py вычисляет π по формуле Чудновских.
verify.py вычисляет π по алгоритму Гаусса—Лежандра.
report.json — полный результат с манифестом 1000 файлов.
manifest.csv — имя, размер, SHA-256, признак отличия каждого файла.
file_0001.txt — представитель группы большинства.
file_0042.txt — единственный отличающийся файл.

Скрипты предназначены для данного архива. Они явно отвергают ряд других
структур архива; это не универсальный инструмент анализа произвольных ZIP.
Исходные записи не изменяются и не запускаются.
